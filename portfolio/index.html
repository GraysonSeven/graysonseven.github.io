04 // ABOUT

I LEARN BY
BUILDING THINGS.

I’m a developer and hands-on builder who likes understanding complete systems — not just one isolated part of them. Software is my strongest documented discipline today, but the same problem-solving mindset carries into mechanical work, fabrication and creative projects.

PROFILE // CL ACTIVE BUILDER
CHARLES LIOC DEVELOPER · BUILDER · PROBLEM SOLVER

I gravitate toward practical problems: workflows that waste time, systems that are unreliable, machines that need to work better, and ideas that are easier to understand once they exist as something real.

01 / APPROACH

UNDERSTAND THE SYSTEM.

Before changing anything, I want to know how the parts interact and where the real constraint actually is.

02 / BUILD

MAKE IT REAL.

I prefer working prototypes and usable products over ideas that stay theoretical for too long.

03 / IMPROVE

ITERATE FROM EVIDENCE.

Test it, find what fails or feels wrong, then improve the actual weak point instead of adding noise.
